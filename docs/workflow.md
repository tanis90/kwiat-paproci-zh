# 本次工作流与已知问题

## 流程

1. **解析** — `mineru-open-api extract -f md,json`，36 页，约 90 秒，产出 131 KB Markdown + 14 张图。
2. **分章** — 按 H1 切成 6 个部分，按 H2 聚合成 36 个翻译单元（每单元 ≤ 4,200 字符）。
3. **术语** — 人工定 [[译名对照表]] v1，覆盖规则术语、属性、神话、民俗、地名、人物。
4. **译** — `open-design/mimo-v2.6-flash`，并发 4，`reasoning_effort: low`。
   36/36 成功，总耗时 1,973 秒，平均 55 秒/节，输入 145 K / 输出 74 K tokens。
5. **校** — 脚本比对专名与结构，人工复核规则数据与民俗词。

## 发现的问题

### 1. 切分器丢失空正文标题（已修）

原 `split.py` 在遇到"标题紧跟标题"时会把前一个空节丢掉。
本书有 7 处这种结构（`## PRZYKŁADOWE ZADANIA W GRZE`、`## ZAKOŃCZENIE`、
`## ELEMENTY FINALU`、`## POMOCE DLA GRACZA`、`## PRZYKŁADOWE SCENY`、
`## Krystynator`、`## DisasterMaster (DM)`）。
已在 `split.py` 修正，并从译文回补标题。**重跑前必须先修，否则会重复丢失。**

### 2. 模型会合并"人名标题 + 台词标题"

原文 `## Krystynator` 常紧跟 `## Odsuń się od okna!...`（角色台词当副标题）。
模型倾向只保留台词。已回补人名标题。

### 3. 日期标题被"提升"

`22 czerwca 1965 r.` 在原文是正文，模型把它变成 `##`，与相邻日记条目一致。
**判定为改进，保留。**

### 4. 两处"守护者"是普通义

`守护者` 出现 2 次，均指"湖中存在的守护者/森林的守护者"，不是 Keeper。
**不是违规**，校对脚本已排除。
